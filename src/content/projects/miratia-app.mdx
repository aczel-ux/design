Miratia is a location-based role-playing game played in real cities. It combines professionally created adventures with user-generated missions built in the companion Miratia Game Maker.

Players discover items across a map made from the real world, solve mysteries, meet unusual characters and explore hidden realms. Collected objects can be used in later games or exchanged for Florin, the game’s currency, which unlocks challenges and useful items.

The visual language balances the familiarity of a mobile map with the playful feedback, collections, characters and progression expected from an adventure game.
