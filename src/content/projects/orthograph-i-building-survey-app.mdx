OrthoGraph I is a professional floor-plan surveying application for iOS and Android. It replaces hand-drawn sketches with an on-site workflow for drawing, measuring and validating existing buildings.

Users sketch a floor plan naturally, add measurements manually or through a connected laser distance meter, and receive feedback when geometry still needs verification.

## Interface across screen sizes

The interface used a fluid layout that worked from compact phones to large tablets. More than fifty views shared a consistent visual language and kept users close to the central drawing workspace.

## Icons and navigation

I designed more than one hundred icons specifically for the application. They communicate tools, states and feedback consistently without competing with the technical content.

Core functions lived in a right-corner wheel menu. Experienced users could move directly between tools, while the same structure guided new users through a complete survey from the initial 2D drawing to a furnished, scale-correct 3D model.

## 3D library

The application included roughly one hundred resource-conscious 3D furniture models, created in Blender. The library covered everyday interiors, basic placeholder geometry and recognizable furniture pieces for more expressive client presentations.
